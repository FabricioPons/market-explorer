Data Pipeline

How raw market files
become structured data

pipeline_clean_lob.py downloads compressed limit order book files in parallel, strips away nested compression layers, and aggregates options data into a clean CSV ready for visualization.

1
URL List Input
A plain text file holds one URL per line, each pointing to a compressed snapshot. File names encode the trading session: loaded_lob_YYYYMMDD_HHMM.csv.gz. Date and limit flags filter the list before processing.
urls.txt date filter limit N
files per session0
2
Parallel Download
8 worker processes run concurrently via ProcessPoolExecutor. Each worker independently fetches one file with 3 automatic retries at 90 s timeout. Results stream to disk as workers complete.
8 workers ProcessPoolExecutor 3 retries
parallel workers0
3
Double Decompress and Parse
Each file is double-gzipped — decompressed twice — revealing a nested JSON string that is itself parsed again. orjson handles decoding at maximum speed with stdlib fallback.
gzip → gzip JSON → JSON orjson
decompression layers0
4
Aggregate and Write CSV
pandas splits records by Bid / Ask side. Two strategies run: a per-minute mean across all 22 numeric fields, plus up to 20 nearest-the-money samples anchored to the ES futures price.
per-side mean ATM samples aggregated_lob.csv
numeric columns0

Visualization Engine

A 3D point cloud that
lives in one HTML file

The builder embeds all data directly into a self-contained HTML — no server needed. Plotly.js renders it as an interactive 3D scatter plot where any three metrics can map to X, Y, and Z axes. Drag to rotate the live simulation below.

Ask side

1
Load and Stratified Sample
Reads aggregated_lob.csv and applies a two-stage strategy: a stratified sample proportional across each dataset × side pair, then an evenly-spaced subset. A max-points cap keeps HTML size manageable.
stratified sample max-points cap
2
Self-Contained HTML Generation
All sampled data is injected as two JS objects: DATA (column arrays) and META (labels, timestamps, side counts). The file opens offline in any browser with no server.
DATA arrays META summaries zero-server
3
3D Point Cloud via Plotly
scatter3d renders data interactively. Any three metrics map to X · Y · Z axes. Color encodes Bid vs Ask, source file, or a continuous metric on a blue to amber to red scale. Five preset views guide users.
scatter3d 3 color modes 5 presets
4
2D Projection and Reading Guides
A companion WebGL scattergl shows any two-axis projection for pattern confirmation. A live reading guide explains axis assignments, and a glossary defines all option-risk metrics.
scattergl WebGL XY · XZ · YZ glossary
