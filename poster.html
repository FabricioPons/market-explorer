Data Pipeline

pipeline_clean_lob.py Python 3 · pandas · orjson
1
URL List Input
A plain text file holds one URL per line, each pointing to a compressed limit order book snapshot. File names encode the trading session date and time: loaded_lob_YYYYMMDD_HHMM.csv.gz. Optional --date and --limit flags filter the list before processing begins.
urls.txt date filter limit N
2
Parallel Download
8 worker processes run concurrently via ProcessPoolExecutor. Each worker independently downloads one file with automatic retry — 3 attempts at 90 s timeout each. Results are streamed to disk as workers complete; order is not guaranteed.
8 workers ProcessPoolExecutor 3 retries / 90 s
3
Double Decompress and Parse
Each file is double-gzipped: decompressed once to reveal a gzip stream, then again to reveal a JSON string, which is parsed to yield another JSON structure — the final list of market records. orjson is used for speed; falls back to stdlib json automatically.
gzip → gzip JSON → JSON orjson fallback
4
Aggregate and Write CSV
Records load into a pandas DataFrame and split by Bid / Ask side. Two strategies run per side: a per-minute mean across all 22 numeric fields, plus up to N nearest-the-money samples anchored to the ES futures price. Output is aggregated_lob.csv — 24 columns, one row per record.
per-side mean ATM samples (N=20) aggregated_lob.csv

Visualization Engine

interactive_3d_builder/ Plotly.js 2.35 · WebGL
1
Load and Stratified Sample
The builder reads aggregated_lob.csv and applies a two-stage strategy: first a stratified sample proportional across each dataset × side combination so no group dominates, then an evenly-spaced subset within each group. A configurable max-points cap keeps HTML size manageable.
stratified sample evenly-spaced subset max-points cap
2
Self-Contained HTML Generation
The renderer injects all sampled data into the HTML template as two JavaScript objects: DATA — column arrays for every metric — and META — dataset labels, timestamp range, row counts, and side summaries. The resulting file needs no server and opens offline in any browser.
DATA column arrays META summaries zero-server HTML
3
3D Point Cloud via Plotly
Plotly.js scatter3d renders the data interactively. Any three metrics map to X · Y · Z axes, swappable freely. Color encodes Bid vs Ask side, source file, or any continuous metric on a blue to amber to red scale. Five preset views guide users from beginner layouts to full option-risk exploration.
scatter3d 3 color modes 5 presets draw-limit slider
4
2D Projection and Reading Guides
A companion WebGL scattergl chart shows any two-axis projection — XY, XZ, or YZ — for pattern confirmation in flat space. Alongside it: a live plain-English reading guide explaining the current axes, per-metric glossary cards, and a source-file summary table with row counts, time spans, and Bid / Ask mix.
scattergl WebGL XY · XZ · YZ reading guide glossary
